# くるひもタイムズ — 編集長のための取扱説明書

## 📁 ファイル構成

```
kuruhimo-times/
├─ index.html    ← デザインと骨組み(基本さわらない)
├─ data.json     ← 記事の中身(毎日ここを編集する)
└─ README.md     ← この説明書
```

毎日触るのは **`data.json` だけ** です。

---

## 🆕 新機能:日付の自動切り替え & ページビュー集計

### 仕組みのおおまかな流れ

1. サイトを開いた瞬間に、JavaScriptが「今日の日付」を取得
2. `data.json` の中から、その日付の記事を選んで表示
3. その記事のページビューを `+1` する(無料カウンターサービスへ)
4. 全記事のビュー数を取得し、TOP5を自動で並べ替えて表示

### 何が自動化されたか

- **発行号数(第○○号)** が創刊日からの日数で自動算出
- **発売日表示** が常に「今日」になる
- **一面記事** と **きょう発売のビジネス書** が日付ごとに切り替わる
- **「よく読まれている記事TOP5」** が、実際のビュー数で自動ランキング

## ✏️ data.jsonの編集ガイド

### 1. 創刊日と天気の設定

```json
"site": {
  "weather": "晴れ・知的好奇心",
  "startDate": "2026-03-21"
}
```

`startDate` を基準に、今日が「第○号」かを自動で計算します。

### 2. 日付ごとに一面記事を切り替える

```json
"topStoryByDate": {
  "default": { 一面記事 },
  "2026-05-01": { 5月1日の一面記事 },
  "2026-05-02": { 5月2日の一面記事 }
}
```

- キーは `YYYY-MM-DD` 形式
- 当日のキーがなければ `default` が表示される
- 各記事には **必ず `id` を付ける**(ビュー集計のため)。例:`"id": "topstory-2026-05-01"`

### 3. アイデア・レビュー・新刊にも `id` が必須

ビュー集計するために、すべての記事に固有のIDを付けます。

```json
{
  "id": "idea-21",
  "num": "21",
  "title": "AIエージェント常駐社会",
  ...
}
```

IDは半角英数字とハイフンで自由につけてOK。一度つけたら変えないこと(変えると集計がリセットされる)。

### 4. 日付ごとに新刊リストを切り替える

```json
"todayBooksByDate": {
  "default": [ ... ],
  "2026-05-01": [ 5月1日発売の本 ],
  "2026-05-02": [ 5月2日発売の本 ]
}
```

## 📊 ページビュー集計の仕組み

### 使っているサービス

[CountAPI.dev](https://counterapi.dev) という無料のカウンターAPIを使っています。
- **登録不要・無料**
- namespace(`kuruhimo-times-2026`)とkey(記事ID)で集計
- リクエストするだけでカウントが+1される

### カウントされるタイミング

- **一面記事**: ページを開いた瞬間に+1
- **アイデアカード・レビュー・新刊**: クリック(タップ)した時に+1
- **同じセッション内で同じ記事を何度クリックしても+1のみ**(水増し防止)

### TOP5ランキングの動き

- 全記事のビュー数を取得して、降順に並べる
- 0ビューの記事は表示しない
- リアルタイムで反映される

### namespaceを変えたい場合

`index.html` 内の `ViewCounter.namespace` を書き換えてください。サイトをリブランドした時や、集計をリセットしたい時に使います。

## 🚀 ローカルでプレビューする方法

`index.html` を直接開くと、ブラウザのセキュリティで `data.json` が読めません。簡易サーバーで動かしてください。

### Mac / Linux
```
python3 -m http.server 8000
```

### Windows
```
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

### VS Code
拡張機能「Live Server」で `index.html` を右クリック →「Open with Live Server」が一番ラク。

## 🌐 公開する方法(Cloudflare Pages推奨)

### 初回セットアップ(15分)

1. **GitHub** でアカウントを作り、リポジトリ「kuruhimo-times」を作成
2. 3ファイルをアップロード
3. **Cloudflare Pages** で「Connect to Git」→ このリポジトリを選択
4. 設定はデフォルトのまま「Deploy」
5. `kuruhimo-times.pages.dev` のURLが発行される

### 日々の更新(2分)

1. 手元の `data.json` を編集して保存
2. GitHub Desktopで「Commit」→「Push」
3. 1〜2分でサイトに反映 ✨

## 💡 編集のコツ

### 効率の良い更新リズム

- **毎日**: `topStoryByDate` に新しい日付キーで一面記事を1つ追加
- **週に1回**: `todayBooksByDate` をまとめて1週間分セットしておく
- **月に1回**: アイデア・レビューを差し替え

### IDの命名規則(おすすめ)

- 一面: `topstory-YYYY-MM-DD`
- アイデア: `idea-NN`
- レビュー: `review-{短いキーワード}`
- 新刊: `book-{短いキーワード}`

### 過去の版に戻したい時

GitHubの履歴から1クリックで戻せる。実験用ブランチを作れば本番影響なし。
